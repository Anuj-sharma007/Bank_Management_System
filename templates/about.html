About Bank Management System

The Bank Management System is a web-based banking application developed to manage basic banking operations in a simple, secure and efficient manner.

The system provides different functionalities for administrators, employees and customers. It allows users to manage customer information, employee records, bank accounts and financial transactions.

The application is developed using Python, Flask, MySQL and Bootstrap. Flask is used for the web application, MySQL is used for database management, and Bootstrap is used to create a responsive and user-friendly interface.

Project Features

  • Role-based access for Admin, Employee and Customer
  • Customer and employee management
  • Bank account management
  • Deposit, withdrawal and fund transfer
  • Transaction history
  • Customer KYC management
  • Employee management
  • Secure login and session management
